Browser Navigation System Using Doubly Linked List

A DSA mini project. Every page you visit becomes a node in a doubly linked list, so Back and Forward are just pointer moves.

This is a browser navigation simulator using a Doubly Linked List. External websites such as YouTube open in a separate browser tab because many websites block iframe embedding. Incognito mode prevents visits from being saved in this project's history, but it is not a replacement for real browser privacy controls.

    Singly vs Doubly Linked List

    Point Singly Linked List Doubly Linked List
    Pointers per node Only next prev and next
    Move to next node O(1) O(1)
    Move to previous node O(n) in the worst case, because we must start from the head and walk forward O(1) when the current node is known, because we follow prev
    Extra memory Less One extra pointer per node
    • A Singly Linked List has no direct pointer to the previous node.
    • To find the previous node in a Singly Linked List, we traverse from the head, which takes O(n) time in the worst case.
    • In a Doubly Linked List, moving to the previous node takes O(1) time when the current node is already known.
    • That is why a Doubly Linked List is more suitable for browser Back and Forward navigation.
